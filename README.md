# Space Adventure Game Promotion Website

架空の宇宙冒険ゲームをテーマに制作したプロモーションWebサイト。<br/>
ピクセルアートを基調としたアートディレクションにより、ゲームの世界観を視覚的に体験できる構成を目指した。

### 制作背景
近年のゲームプロモーションサイトには、情報提供だけでなく、ゲームの世界観や雰囲気を伝える役割が求められている。<br/>
本制作では、ユーザビリティを維持しながら、アートディレクションを通じて世界観を一貫して表現することを目的として制作した。

### コンセプト
本プロジェクトでは、単なる情報提供ではなく、「ゲームの世界観を体験できるWebサイト」を目指した。<br/>
ピクセルアートを基調としたビジュアル表現により、レトロゲームに親しみのあるユーザーへ没入感と親近感を与え、ゲームテスター募集への参加を促す構成としている。<br/>
また、フォント・配色・UI・アニメーションを統一することで、一貫したビジュアルアイデンティティを構築した。

### 工夫したポイント

#### アートディレクション
- ピクセルアートを単なるレトロ表現ではなく、「ゲーム世界観を伝える視覚言語」として設計
- フォント・配色・UI表現を統一し、一貫したビジュアル体験を構築

#### UI
- シングルページ構成により、必要情報へスムーズにアクセス可能
- テスター募集を目的として、情報量を整理し重要要素へ視線誘導
- 鮮やかな配色を用いながら、可読性を損なわないコントラスト設計を意識

### 成果
ピクセルアートを活用したビジュアル表現により、ゲームの世界観を直感的に伝えるプロモーションサイトを制作した。<br/>

本制作を通じて、フォント・配色・UI・ビジュアルスタイルを統合し、一貫した視覚言語として設計するアートディレクションの理解を深めた。<br/>

また、ユーザビリティとビジュアル表現を両立する設計力を高めることができた。
